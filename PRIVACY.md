# Privacy

Growth Skills is a set of Claude skills made of text references and small Python scripts (a report-card renderer and a test-duration calculator). The scripts run locally, read only the files you give them and make no network calls. There are no MCP servers and no hooks.

- It does not collect, store or transmit any personal data.
- It sends nothing to the author or to any third party.
- Whatever you share with Claude while using the skills is handled by Claude under Anthropic's own privacy policy: https://www.anthropic.com/legal/privacy

Questions: open an issue at https://github.com/theoutlines/growth-skills/issues
